# Customer Segmentation Project

A machine learning project that uses K-Means clustering to group customers based on their annual income and spending scores.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Features
- Customer segmentation using K-Means
- Cluster summary and customer analysis
- Visualizations of customer groups
- Silhouette score evaluation

## How to Run
Install the required libraries and run `customer_segmentation.py`.
